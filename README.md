## English

A bilingual portfolio for software engineering work, experiments, and ideas. Its Home brings a chess-inspired 3D scene together with the portfolio's projects and engineering labs.

All 13 page routes are generated by Astro. Shared layouts and new UI components use TypeScript; React controls Labs selection and the About player/mixer. Existing Three.js, Canvas and Web Audio engines remain JavaScript modules. Projects retains its placeholder content.

About uses native scroll to dissolve Music, Art and Games inside a pinned stage. Art keeps its text in HTML, with a shared reveal mask, pointer-responsive smoke and a separate foreground flower. Reduced motion and disabled JavaScript retain a normal document flow. Opt-in audio continues through the page; Games currently provides a static coming-soon cover with Play disabled.

Contact Beta 1 uses five photographic atmospheres with optional, pausable transitions and a static fallback. Scene controls let visitors select an atmosphere; continuous rain, moving commuters, and audio are not implemented.


### Technologies

`Astro` · `TypeScript` · `React` · `CSS` · `JavaScript ES modules` · `Three.js`<br />
Node.js 24.22.1 and npm are required. The build generates static files; there is no application server in production.

## Português

Um portfólio bilíngue de engenharia de software, experimentos e ideias. A Home combina uma cena 3D inspirada no xadrez com projetos e laboratórios de engenharia.

As 13 rotas são geradas por Astro. Layouts compartilhados e novos componentes usam TypeScript; React controla a seleção de Labs e o player/mixer de About. Os motores Three.js, Canvas e Web Audio continuam em JavaScript. Projects mantém seu conteúdo provisório.

About usa scroll nativo para dissolver Music, Art e Games num palco fixo. Art mantém texto em HTML, com uma máscara de formação compartilhada, fumaça que reage ao ponteiro e flor independente no primeiro plano. Com movimento reduzido ou JavaScript desligado, o conteúdo segue no fluxo normal. O áudio iniciado pelo visitante continua pela página; Games apresenta somente uma capa estática de Em breve, com Play desabilitado.

A Contact Beta 1 usa cinco atmosferas fotográficas, transições opcionais com pausa e fallback estático. Os controles da cena permitem escolher uma atmosfera; chuva contínua, passageiros em movimento e áudio ainda não estão implementados.


### Tecnologias

`Astro` · `TypeScript` · `React` · `CSS` · `JavaScript ES modules` · `Three.js`<br />
É necessário Node.js 24.22.1 e npm. O build gera arquivos estáticos; não há servidor de aplicação em produção.

## Run locally / Executar localmente

```powershell
git clone https://github.com/devbrunoflorian/portfolio.git
cd portfolio
npm ci
npm run dev
```

Open one of these pages:

- English: <http://127.0.0.1:4173/en/>
- Português: <http://127.0.0.1:4173/pt-br/>

Press `Ctrl+C` in the terminal to stop the preview server.

The legacy root-level preview server does not serve the migrated pages. Use the npm commands above.

```powershell
npm run check
npm test
npm run build
npm run check:build
npm run preview
```

Browser regression checks require Playwright's Chromium:

```powershell
npx playwright install chromium
npm run build
npx playwright test
```

Browser tests run against the production build and cover routes, controls, static fallbacks and selected lifecycle scenarios. They do not certify physical mobile performance or complete musical playback. Score integration and adaptive rendering budgets remain separate work.

For static hosting, use `npm run build` and publish only `dist`. The build preserves page URLs and stages assets discovered from current src files and their dependencies. Source files, development tools and experiments are not deployment inputs.
